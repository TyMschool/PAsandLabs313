The main bottleneck is the tiny buffer size (256 bytes) and high per-request overhead.

File Size | Time (seconds)
----------|---------------
1KB:       0m1.102s
10KB:       0m1.098s
100KB:       0m1.129s    <---Lots of overhead. Takes about the same time as the 1KB!
1MB:       0m1.460s
10MB:       0m5.585s   <--- Constrained by the small chunk size, making these slower
100MB:       0m27.439s
See answer.png for the graph of the above table. The x-axis is file size (in MB) and the y-axis is time (in seconds).
