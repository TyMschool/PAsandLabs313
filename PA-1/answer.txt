The main bottleneck is the tiny message size (256 bytes) and high per-request overhead.

Effect: 100MB file requires ~450,000 requests, making transfers slow (~3.6 MB/s) despite larger file size improving efficiency slightly.
The system’s architecture favors many tiny requests over bulk transfer, causing slow performance.
